# IQD to RMB Calculator

A simple web application to convert Iraqi Dinar (IQD) to Chinese Yuan (RMB) and calculate a 0.3% fee.

## Features

- Convert IQD to RMB using the current exchange rate
- Calculate a 0.3% fee on the IQD amount
- Clean, responsive user interface
- Input validation for positive numeric values only
- Accessible design with proper ARIA attributes

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)

## How to Use

1. Enter an amount in Iraqi Dinar (IQD) in the input field
2. Click the "Calculate" button or simply type in the field
3. View the calculated 0.3% fee and the equivalent amount in Chinese Yuan (RMB)
4. Use the "Clear" button to reset the form

## Exchange Rate

The application uses the following conversion rates:
- 0.3% fee calculation: IQD amount × 0.003
- IQD to RMB conversion: IQD amount × 0.00548847420417124
